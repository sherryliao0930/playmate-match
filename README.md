# 畢旅玩伴配對

六年九班（27 人）九族文化村＋劍湖山世界的分組調查網站。
學生在網頁上選「膽量、喜歡的設施類型、想一起玩的同學、想避免同組的同學（需填原因）」，按一下送出即可——**不需要抄任何代碼**。
老師在同一個網站的「老師專區」讀取全班回覆、自動分組、下載 CSV。
分組只是建議，老師可以依班級狀況調整。

```
playmate-match/
├─ index.html       ← 整個網站（單一檔案，直接放上 GitHub Pages）
├─ apps-script.gs   ← 收件程式，貼到 Google Apps Script
└─ README.md
```

---

## 一、先做收件信箱（約 5 分鐘，只做一次）

1. 到 [Google 試算表](https://sheets.new) 開一個新檔案，取名例如「畢旅玩伴調查」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把 `apps-script.gs` 的內容**全部貼上**，覆蓋原本的 `myFunction`。
4. 把第 17 行的密碼改掉：

   ```js
   const TEACHER_KEY = '改成你的密碼';
   ```

5. 按 💾 儲存，再按右上角 **部署 → 新增部署作業**：
   - 類型（齒輪圖示）：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**任何人** ← 一定要選這個，學生才送得出來
6. 第一次會要你授權，按 **審查權限 → 選自己的帳號 → 進階 → 前往（不安全）→ 允許**。
7. 複製最後出現的**網頁應用程式網址**，長得像：

   ```
   https://script.google.com/macros/s/AKfycb................/exec
   ```

> 之後若修改了 `apps-script.gs`，要再按一次「部署 → 管理部署作業 → ✏️ → 版本選『新版本』→ 部署」，網址不會變。

---

## 二、把網址填進網站

打開 `index.html`，最上面有一塊設定區，只改 `endpoint` 這一行：

```js
const CONFIG = {
  endpoint: 'https://script.google.com/macros/s/AKfycb................/exec',
  teacherKey: ''   // ⚠️ 保持空白，不要填密碼
};
```

> ### ⚠️ `teacherKey` 為什麼要留空
>
> 這個網站放在**公開的 GitHub repo**，任何人按瀏覽器的「檢視網頁原始碼」都看得到 `index.html` 的每一行。
> 密碼一旦寫進去，等於公開張貼，別人就能用 `?action=list&key=密碼` 讀走全班資料，
> 包括學生私下寫的「避免同組」與原因。
>
> 正確做法是留空，老師第一次進「老師專區」時在密碼欄輸入一次，
> 瀏覽器會存在本機（localStorage），同一台裝置之後不用再輸入。

> `endpoint` 留空時網站會進入**示範模式**：畫面全部正常，但送出的答案只會留在那台裝置上。

---

## 三、放上 GitHub Pages

1. 在 GitHub 建一個 repository（公開即可）。
2. 把 `index.html` 上傳到 repository 根目錄（`apps-script.gs` 和 `README.md` 放不放都行）。
3. 進 **Settings → Pages**，Source 選 **Deploy from a branch**，分支選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等一兩分鐘，網址會長這樣：`https://<你的帳號>.github.io/<repo 名稱>/`
5. 把這個網址發給學生就好。

---

## 四、學生怎麼用

點網址 → 七個步驟，約兩分鐘：

1. 點自己的名字
2. 膽量 1～5
3. 勾喜歡的設施類型（可複選，附兩園真實設施清單與身高限制）
4. **九族**想一起玩的同學（可複選、可不選）
5. **劍湖山**想一起玩的同學（可複選、可不選）
6. **這次想避免跟誰同一組**（可複選、可不選；每選一位都要**寫下原因**，🔒 只有老師看得到）
7. 想跟老師說的話（非必填）

按「🎉 送出給老師」就完成，答案直接進老師的 Google 試算表。
填錯可以重新開網頁再填一次，系統以**最後一次**為準。

---

## 五、老師怎麼用

頁尾點「老師專區 →」：

- 輸入密碼 → **↻ 讀取最新回覆**
- 看回收進度、還沒交的名單、全班平均膽量、最熱門類型
- 四種分組模式，自動產生**兩個樂園各自的分組**（九族和劍湖山可以分成不同組）：

  | 模式 | 結果 |
  |---|---|
  | **彈性 2～4 人**（預設） | 不強迫均分。從最合得來的兩個人開始長，下一個人跟整組契合度夠高才加進來，最多 4 人，不夠就停在 2 或 3 人。同一次分組會同時出現 2 人、3 人、4 人的組 |
  | 固定 2 人 | 每組一律 2 人（27 人 → 12 組 2 人＋1 組 3 人） |
  | 固定 3 人 | 每組一律 3 人（27 人 → 9 組） |
  | 固定 4 人 | 每組一律 4 人（27 人 → 6 組 4 人＋1 組 3 人） |

  不管哪種模式，每組都保證落在 2～4 人，不會有人落單。

- 每組顯示：**組長**、成員、平均膽量、共同喜好類型、**玩伴心願達成率**、建議路線

### 👑 組長

每組自動推薦一位組長：**組內被最多人點名想一起玩的人**，
其次看全班被點名數與膽量。組長在名單上有 👑 和黃底標示。

想換人就用組別卡片下方的「組長」下拉選單直接選，
分組圖和 CSV 都會跟著更新。組長搬到別組時，原組會自動由下一位遞補。

### ✋ 手動調整

分組只是建議，老師可以直接改：

- **點學生的名字** → 再點別組的「移到這組」，就換組了
- **➕ 新增一組** → 把人移進去；組被搬空會自動消失，空組也可以按「✕ 刪掉這個空組」
- 一組超過 4 人會被擋下，低於 2 人或超過 4 人的組會跳 ⚠️ 提醒
- **↺ 重新自動分組** 可以丟掉手動調整、重算一次
- 調整結果存在瀏覽器本機，關掉網頁再打開還在；CSV 和分組圖都以**調整後**的結果輸出

### 🖼️ 分組圖

每個樂園的分組區塊右上角有 **🖼️ 下載分組圖**，會產生一張遊樂園風格的 PNG
（2560px 寬，彩旗、票根卡片、每組一個遊樂設施圖示），
含**組長（👑 黃底標示）**、成員名字、平均膽量、共同喜好與建議路線，
可以直接印出來貼在教室或發到群組。
- 標出**沒有被任何人點名的同學**，方便多關照
- 🔒 **避免同組達成率**；若某一組還是把兩個人排在一起，該組會出現 ⚠️ 提醒，可手動微調
- 下載兩份 CSV（UTF-8 BOM，Excel 不亂碼）：
  - 填答原始資料（含每人的分組編號）
  - 分組結果（含每組建議路線）
- 也可以把 Google 試算表「下載成 CSV」後用 **📂 匯入試算表 CSV** 讀進來

## 六、設施怎麼分類的

兩園共用同一套七類，才有辦法互相配對：

| 類型 | 九族代表設施 | 劍湖山代表設施 |
|---|---|---|
| 🎢 心臟很大顆 | 馬雅探險、UFO 幽浮歷險（85m，全台最高） | 飛天潛艇 G5（5G）、衝瘋飛車、擎天飛梭 |
| 🌊 濕了也不怕 | 金礦山探險、無敵艦隊、大漩渦 | 尖叫無底洞、龍捲風、大碗公（夏季） |
| 👻 愛被嚇 | VR 風暴幽靈船、侏羅紀探險 | 驚嚇列車（AR 鬼屋）、VR Dino |
| 🎡 歡樂溫和 | 碰碰車、音樂馬車、單軌電車 | 幸福摩天輪、彩虹列車、咕咕飛車 |
| 🌸 美景拍照 | 日月潭纜車、櫻花大道、歐洲花園 | 和園花園、彩虹步道、鳳梨吊橋 |
| 🎭 表演手作 | 娜魯灣劇場、琉璃珠 DIY、原住民部落區 | 彩虹劇場、柯南主題樂園（期間限定） |
| 🍧 吃吃喝喝 | 廣場市集、等路大街 | 柯南主題餐廳、KU 代美食廣場 |

配對分數：互相點名 7 分 ＞ 單方點名 3 分，再加設施類型重疊度（最高 5 分）與膽量接近度（最高 2 分）；
只要任一方勾了「避免同組」就扣 100 分，等同盡量不排在一起。
想玩的東西差太多的人不會被硬湊在一起。

### 🔒 關於「避免同組」這一題

第 6 題直接問「這次想避免跟誰同一組？」，**每選一位都必須寫下原因**（至少 2 個字，最多 60 字），
沒寫就不能按下一步。網頁提供六個常見說法可以一點即填，也可以自己打：

> 在一起會分心　／　常常吵架　／　之前有不愉快　／　想認識別的同學　／　想玩的東西差很多　／　跟他一組會不自在

原因存在試算表的「原因」欄，順序和「避免同組」欄一一對應。

隱私處理：

- 可以完全不選，沒有的話空著直接下一步
- 學生送出後的完成畫面**不顯示名字和原因**，只顯示「已私下告訴老師（N 人）」，避免旁邊同學看到
- 老師專區的表格**預設把這一欄收起來**，要按「👁️ 顯示」才看得到；投影或請學生幫忙時請不要打開
- 下載的 CSV 會包含這一欄（標示「想避免同組＋原因（保密）」），請妥善保管、不要轉述給任何人
- 若有人寫的原因提到衝突或霸凌，分組之外也值得另外了解

資料整理自兩園官網（含劍湖山「各項設施搭乘限制」頁）與多篇遊記。
**出發前請再對一次官網**：劍湖山水樂園僅夏季開放，柯南主題樂園為期間限定，設施也可能逢保養日停開。

## 七、要改名單時

`index.html` 裡的 `STUDENTS` 陣列，格式是 `[座號, '姓名']`：

```js
const STUDENTS = [
 [1,'蔡禮陽'],[2,'曾恆駒'], ... [33,'李晴萱']
];
```

增刪一行即可，其他地方都會自動跟著變。
